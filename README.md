# Fitness Calculator
A simple Python console app created as part of my software development learning journey

## Features

- Tracks cycling and swimming activity
- Calculates total weekly exercise time
- Uses conditional logic (if, elif, else)
- Demonstrate variables, user input, and artihmetic
